# 雅思词汇单次复盘

## 第 1 次辅导

### 本轮目标

- 建立适合四级基础考生的雅思背词方法
- 完成第一组 `education + technology` 高频词学习
- 开始把单词迁移到口语和写作表达里

### 本轮收获

- 雅思词汇学习不等于只背中文意思。
- 真正影响分数的是：词汇范围、准确性、搭配、改写能力、拼写和语境使用。
- 现阶段最重要的不是追求难词，而是把高频核心词用准。

### 当前薄弱点判断

- 大概率存在“会认不会用”
- 可能存在“单词会背，搭配不会”
- 可能存在“作文和口语里重复简单词”

### 今日最小任务

1. 学完 `study/ielts-vocabulary-notes.md` 里的 `15` 个词
2. 完成 `5` 个中文转英文
3. 完成 `3` 个改写句
4. 回答 `2` 个口语问题

### 你回传给我的内容

你做完后，直接把下面内容发给我，我会继续一对一批改：

1. 你写的 `5` 句中译英
2. 你改写后的 `3` 句英文
3. 两道口语题的答案
4. 你最容易混淆的 `3-5` 个词

### 我会怎么辅导你

- 我会逐句改，不只改语法，也会改：
  - 选词是否自然
  - 搭配是否地道
  - 哪些地方还是中式英语
  - 哪些简单词该保留，哪些地方值得升级

### 下一轮验收标准

- `15` 个词里至少掌握 `10` 个
- 至少能自然使用 `8` 个词
- 至少能做出 `3` 处有效改写，而不是只机械替换高级词
