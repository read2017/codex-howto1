# Codex Day 5 掌握检查：Skills

## 主题

- 要检查的知识或技能：
  - 理解 Codex `Skill` 的职责、结构、触发方式与最小写法

## 当前判断

- 我认为自己在哪一层：
  - 从“知道概念”进入“准备自己写一个最小 skill”
- 为什么这样判断：
  - 已经有 Day 5 学习笔记、速查卡和一个 skill 草稿
  - 还需要通过复述和改写练习把概念转成可操作能力

- 我能复述什么：
  - `Skill` 是可复用工作流
  - `AGENTS.md` 是项目级总规则
  - skill 的关键是 `description`、边界和输出
- 我能完成什么：
  - 读懂一个最小 `SKILL.md`
  - 判断一个流程是否适合做成 skill
- 我能修改或迁移什么：
  - 把学习笔记整理流程改写成适合本仓库的 skill 草稿

- 最不稳的概念：
  - `description` 应该写多宽、多窄
- 最容易犯的错：
  - 把 skill 写成一段过宽、过长、边界不清的说明书
