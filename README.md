# Codex Training Notes

一份面向中文使用者的 Codex 学习与培训仓库。

这份仓库不是官方文档镜像，也不是“功能清单大全”，而是把 Codex 的学习过程整理成可复用的培训材料、学习笔记、速查卡、错题整理和练习产出，方便个人自学、团队内训和后续迭代。

## 这个仓库适合谁

- 想系统学习 Codex 的中文用户
- 想给团队做 Codex 内训的人
- 想把学习过程沉淀成文档而不是只停留在聊天记录里的人
- 想继续扩展到 `Skill`、`MCP`、安全边界、工作流设计的人

## 你能在这里学到什么

- Codex 的基本心智模型
- 如何设计更有效的任务描述
- `sandbox`、`approval`、网络边界的区别与风险判断
- `Skill` 的作用、写法和最小结构
- MCP 的整体架构、角色分工与安全观
- 如何把学习过程整理成可复用的 Markdown 资产

## 这个仓库的内容组织方式

为了让学习过程可复盘、可检查、可继续扩展，这个仓库优先使用以下几类文档：

- 学习笔记：解释概念、整理框架
- 速查卡：帮助快速复习和回忆
- 错题整理：记录误区、错误答案和纠偏结论
- 掌握检查：判断当前掌握层级
- 复盘：总结本轮收获、卡点和下一步动作

这套组织方式的目标不是“把聊天记录保存下来”，而是把学习过程改写成以后还能单独阅读和继续使用的资产。

## 如何使用这个仓库

### 如果你是自学

建议按这个顺序：

1. 阅读培训大纲，先建立整体认知
2. 进入 `codex-learning/`，按主题逐篇看学习笔记和速查卡
3. 做掌握检查里的小题和微产出任务
4. 把自己的理解和错题继续补到同目录下

### 如果你是做团队培训

建议这样用：

1. 先用大纲和 `codex-headline.md` 组织讲授顺序
2. 用 `ppt/` 中的内容做展示
3. 用 `codex-learning/` 中的速查卡和错题整理做课后资料
4. 按团队实际场景继续补充新的 Day N 文档
